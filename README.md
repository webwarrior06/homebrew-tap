# webwarrior06/homebrew-tap

```sh
brew install --cask webwarrior06/tap/nuticast
```

This installs the Nuticast menu bar app and puts the `nuticast` command on your PATH.

Nuticast makes an iPhone on a different Wi-Fi show up in Xcode as a wireless debug device, over Tailscale, ZeroTier, or Netbird. https://www.nuticast.com
